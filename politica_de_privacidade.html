Política de Privacidade — Lógica

Última atualização: 29/10/2026

Esta política explica quais informações o app Lógica trata. Ao usar o app, você concorda com o que está descrito aqui.

1. Quem é responsável

O app é desenvolvido por felipevasc. Contato: abra uma issue em github.com/felipevasc/logica-privacidade/issues.

2. Dados que o app não coleta

O Lógica não coleta nome, e-mail, localização, contatos, fotos, áudio de microfone, identificadores de publicidade nem dados de uso para análise. Não exibe anúncios e não contém compras dentro do app.

3. Dados salvos no seu aparelho

Seu progresso (níveis, estrelas, pontos, configurações e a aparência da sua princesa) fica salvo apenas no seu aparelho. Esses dados não são enviados para nós. Ao desinstalar o app, esses dados são apagados.

4. Backup na nuvem (opcional)

Se o desenvolvedor ativar o backup na nuvem em uma versão do app, o progresso pode ser salvo no Firebase (Google), usando um identificador anônimo criado pelo próprio app, sem nome, e-mail ou telefone. Esse recurso serve apenas para restaurar seu progresso. Esta política será atualizada antes de qualquer versão com esse recurso ser publicada.

5. Permissões

O app usa apenas a permissão de vibração, para dar retorno tátil nos acertos e erros. Não pede acesso a câmera, microfone, localização, contatos ou arquivos.

6. Crianças

O app não coleta informações pessoais de crianças. Como não há coleta, não há compartilhamento com terceiros.

7. Seus direitos

Você pode apagar todos os dados do app a qualquer momento desinstalando-o. Para dúvidas ou pedidos, abra uma issue em github.com/felipevasc/logica-privacidade/issues.

8. Alterações

Se esta política mudar, a nova versão será publicada nesta mesma página, com a data de atualização.
